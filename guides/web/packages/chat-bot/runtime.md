# Работа бота

## Возобновление после перезапуска {#checkpoint}

С настройкой [`checkpoint`](./configuration.md#checkpoint) `bot.start()` продолжает обработку
с сохранённого номера события. Бот сохраняет номер после успешной обработки события и всех
предыдущих. После ошибки обработчика при следующем запуске бот может снова получить часть событий.

Чтобы начать с конкретного номера, передайте его в `bot.start(eventSeq)`. Если подключались
к событиям напрямую через `itd.chats.events.connect()`, сначала вызовите
`itd.chats.events.disconnect()`.

## Очередь и параллельная обработка {#queue}

События одного чата обрабатываются по порядку. При переполнении очереди бот заканчивает
принятую работу и пытается догрузить пропущенные события. Размер очереди и количество
одновременно обрабатываемых чатов задаются в [конфигурации](./configuration.md#queue).

## Ошибки обработчиков

Для ошибок команд и middleware используйте `bot.catch((error, ctx) => ...)`.
По умолчанию эти ошибки выводятся в логгер клиента или в консоль.

Для отдельного модуля можно настроить [свой обработчик ошибок](./routing.md#ошибки-отдельной-ветки).
