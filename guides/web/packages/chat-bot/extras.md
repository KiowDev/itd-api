# Дополнительные возможности

## Ограничение частоты

`RateLimiter` ограничивает частоту обработки входящих событий. Его можно подключить через
`use()` для всего бота, модуля или отдельной команды. Поставьте его перед нужным обработчиком.

Например, каждый пользователь может вызвать `/спросить` до пяти раз за 10 секунд:

```ts
import { RateLimiter } from '@itd-api/chat-bot';

const ask = bot.command('спросить');
ask.use(new RateLimiter({
  limit: 5,
  window: 10_000,
  onLimit: (ctx) => ctx.reply('Слишком много запросов. Попробуйте чуть позже.'),
}));
ask.use(handleQuestion);
```

Окно начинается с первого события по ключу. При первом превышении вызывается `onLimit`.
Если его опустить, лишние события отбрасываются молча. Счётчики хранятся в памяти экземпляра.

### Свой ключ для реакций и удалений

По умолчанию ограничитель считает входящие сообщения по отправителю. Для ветки реакций
или удалений можно задать лимит на чат через `key: (ctx) => ctx.chatId`. Если ключ не определён,
событие проходит дальше.

```ts
import { RateLimiter } from '@itd-api/chat-bot';
import { ChatUpdateType } from 'itd-api';

bot.on(ChatUpdateType.MessageReactions)
  .use(new RateLimiter({ limit: 10, window: 5_000, key: (ctx) => ctx.chatId }))
  .use(handleReaction);
```
